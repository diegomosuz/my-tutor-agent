# Laboratorio — Scheduler de instrucciones

Construya un simulador simple con latencias configurables y dos unidades funcionales. A partir de un bloque RISC-V abstracto:
- cree DAG de dependencias;
- calcule critical path;
- aplique list scheduling;
- reporte ciclos;
- mida presión máxima de valores vivos.

Luego modele un loop y calcule `ResMII` y `RecMII` para un esquema de software pipelining.
