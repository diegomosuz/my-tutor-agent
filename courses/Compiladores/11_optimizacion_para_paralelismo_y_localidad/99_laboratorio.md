# Laboratorio — Transformaciones de loops y localidad

Use matrix multiplication y dos kernels adicionales.

1. Mida versiones `ijk`, `ikj` y tiled.
2. Explique locality espacial/temporal de cada acceso.
3. Para una transformación propuesta, escriba las dependencias que justifican su legalidad.
4. Detecte al menos una reducción y discuta reproducibilidad de floating point.

La entrega debe contener datos de benchmark **y** explicación del modelo de memoria que los interpreta.
