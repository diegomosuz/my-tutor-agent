# 19.0 — Objetivos del proyecto por competencias

> **Capítulo 19: Proyecto integrador con SDD y agentes.** Competencias globales del capítulo:
> - Realizar un proyecto incremental con agente implementador y revisor.
> - Defender matemáticamente la solución.

## Competencias de esta sección

- **Conocimiento:** definir con precisión los términos y expresiones de «objetivos del proyecto por competencias».
- **Desempeño:** aplicar el cálculo de predicados y las transformaciones justificadas en un problema concreto.
- **Evidencia:** entregar una especificación o derivación anotada, con hipótesis explícitas y límites de validez.

> **Material complementario original:** aplicación actual de los métodos de Kaldewaij; no corresponde a una sección del libro de 1990.

## Desarrollo

### Proyecto final: motor de evaluación de reglas

El proyecto consiste en construir un servicio Python que evalúa una colección acotada de reglas de aceptación de registros y devuelve un dictamen, el conjunto de reglas aplicadas y una traza verificable. Se trabaja mediante features SDD independientes, cada una acompañada de un contrato y evidencia de corrección proporcional a su riesgo.

**Competencias integradoras:** pasar de un requisito ambiguo a predicados precisos; derivar las decisiones sin contradicciones; construir invariantes para agregaciones; implementar en Python; explicitar fronteras de sistemas externos; y revisar críticamente las explicaciones de un agente.

**Entrega:** repositorio con código, specs, derivaciones, pruebas y bitácora de decisiones. No se exige plataforma adicional; un entorno local y ejecución de pruebas bastan.

## Comprobación de competencia

1. Formula la propiedad central como un predicado explícito, indicando el dominio y las condiciones de definibilidad.
2. Justifica una transformación algebraica relevante sin usar solo ejemplos concretos como prueba.
3. Construye un caso límite que pueda refutar una hipótesis insuficiente.
4. Declara qué parte está demostrada y cuál constituye solamente evidencia experimental.
