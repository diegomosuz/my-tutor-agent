# 17.2 — Derivación de un agregador incremental

## Competencias de esta sección

- **Conocimiento:** definir con precisión los términos y expresiones de «derivación de un agregador incremental».
- **Desempeño:** aplicar el cálculo de predicados y las transformaciones justificadas en un problema concreto.
- **Evidencia:** entregar una especificación o derivación anotada, con hipótesis explícitas y límites de validez.

> **Material complementario original:** aplicación actual de los métodos de Kaldewaij; no corresponde a una sección del libro de 1990.

## Desarrollo

### Derivación de un agregador incremental

Generalizamos el límite constante `N` a una frontera `n`. Elegimos:

$$I:\quad 0\leq n\leq N\land s=(\sum i:0\leq i<n\land valid(X.i):amount(X.i)).$$

La inicialización `n,s:=0,0` establece el invariante porque la suma sobre rango vacío es cero. Para `n<N`, el *split-off* del último término nos da dos ramas:

$$valid(X.n)\Rightarrow s'=s+amount(X.n),$$
$$\neg valid(X.n)\Rightarrow s'=s.$$

Esto produce:

```text
n,s := 0,0;
do n<N ->
    if valid(X.n) -> s,n := s+amount(X.n),n+1
    [] ¬valid(X.n) -> n := n+1
    fi
od
```

**Terminación:** `t=N-n` es entero no negativo y decrece en cada rama. **Complejidad:** `O(N)` evaluaciones; `O(1)` memoria auxiliar, sin contar las entradas. Esta derivación es válida bajo el contrato de que `valid` y `amount` terminan y no alteran el arreglo.
