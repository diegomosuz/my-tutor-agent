# 20.8 — Mantenimiento, criterios de aceptación y límites

## Competencias de esta sección

- **Conocimiento:** definir con precisión los términos y expresiones de «mantenimiento, criterios de aceptación y límites».
- **Desempeño:** aplicar el cálculo de predicados y las transformaciones justificadas en un problema concreto.
- **Evidencia:** entregar una especificación o derivación anotada, con hipótesis explícitas y límites de validez.

> **Material complementario original:** aplicación actual de los métodos de Kaldewaij; no corresponde a una sección del libro de 1990.

## Desarrollo

### Mantenimiento y criterios de calidad

Una skill bien diseñada debe ser corta, repetible, acotada a una responsabilidad y tener entradas y salidas identificables. Evitar instrucciones como "demuestra que todo es correcto". Especificar qué obligaciones deben comprobarse y cómo manejar una prueba incompleta.

**Validación antes de integrar:** ejecutar la skill con una derivación correcta y otra deliberadamente incorrecta; verificar si el agente rechaza la segunda con contraejemplo. Revisar la compatibilidad de Markdown, las rutas y el nombre de la herramienta elegida.

### Checklist del último capítulo

- [ ] Se comprende el uso de `actividades/`, `plantillas/`, `recursos/` y `skills/`.
- [ ] Se puede crear una nueva skill en un archivo `SKILL.md`.
- [ ] Se reconoce la diferencia entre prueba lógica, test y confianza del agente.
- [ ] Se puede aplicar el flujo completo a una feature SDD pequeña.
- [ ] Se informa explícitamente cualquier obligación no demostrada.

**Meta de transferencia:** utilizar la formalidad de Kaldewaij donde reduce errores de diseño, sin convertir cada pequeña modificación en un proceso documental pesado.

## Comprobación de competencia

1. Formula la propiedad central como un predicado explícito, indicando el dominio y las condiciones de definibilidad.
2. Justifica una transformación algebraica relevante sin usar solo ejemplos concretos como prueba.
3. Construye un caso límite que pueda refutar una hipótesis insuficiente.
4. Declara qué parte está demostrada y cuál constituye solamente evidencia experimental.
