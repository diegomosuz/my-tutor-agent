# 20.5 — Crear una skill de contratos formales

## Competencias de esta sección

- **Conocimiento:** definir con precisión los términos y expresiones de «crear una skill de contratos formales».
- **Desempeño:** aplicar el cálculo de predicados y las transformaciones justificadas en un problema concreto.
- **Evidencia:** entregar una especificación o derivación anotada, con hipótesis explícitas y límites de validez.

> **Material complementario original:** aplicación actual de los métodos de Kaldewaij; no corresponde a una sección del libro de 1990.

## Desarrollo

### Skill `formal-contract`: procedimiento derivado

1. Leer los requisitos, distinguir constantes de variables y definir un espacio de estados.
2. Escribir `P` y `Q` mediante predicados comprobables; evitar predicados que oculten requisitos ambiguos.
3. Identificar expresiones parciales (`div`, índices, llamadas externas) e incorporar definibilidad.
4. Registrar resultados alternativos en una selección por guardas; probar cobertura.
5. Entregar un archivo `contract.md` con `{P}S{Q}`, hipótesis y contraejemplos relevantes.

Ejemplo: `Q = 0≤p≤1 ∧ p=response.prediction` requiere comprobar ambas condiciones antes de devolver `SUCCESS`.

**Criterio de aceptación:** las precondiciones son suficientes para que las expresiones necesarias estén definidas y cada resultado posible tiene una condición clara.

## Comprobación de competencia

1. Formula la propiedad central como un predicado explícito, indicando el dominio y las condiciones de definibilidad.
2. Justifica una transformación algebraica relevante sin usar solo ejemplos concretos como prueba.
3. Construye un caso límite que pueda refutar una hipótesis insuficiente.
4. Declara qué parte está demostrada y cuál constituye solamente evidencia experimental.
