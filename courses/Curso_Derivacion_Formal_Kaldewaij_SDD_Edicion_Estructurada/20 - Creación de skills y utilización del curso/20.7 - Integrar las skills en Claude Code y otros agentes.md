# 20.7 — Integrar las skills en Claude Code y otros agentes

## Competencias de esta sección

- **Conocimiento:** definir con precisión los términos y expresiones de «integrar las skills en claude code y otros agentes».
- **Desempeño:** aplicar el cálculo de predicados y las transformaciones justificadas en un problema concreto.
- **Evidencia:** entregar una especificación o derivación anotada, con hipótesis explícitas y límites de validez.

> **Material complementario original:** aplicación actual de los métodos de Kaldewaij; no corresponde a una sección del libro de 1990.

## Desarrollo

### Integración operativa en un repositorio SDD

```text
proyecto/
├── specs/
│   └── 004-api-inferencia/
│       ├── spec.md
│       ├── plan.md
│       ├── derivation.md
│       └── tasks.md
├── .claude/
│   └── skills/
│       ├── formal-contract/SKILL.md
│       ├── formal-derive/SKILL.md
│       ├── formal-review/SKILL.md
│       └── formal-evidence/SKILL.md
└── tests/
```

Para Claude Code se puede copiar el contenido de `skills/` bajo el directorio de skills que soporte la instalación del proyecto; comprobar en la documentación de la versión utilizada cómo se descubren/invocan. En otros agentes, reutilizar el texto procedimental en sus mecanismos de instrucciones, sin asumir compatibilidad automática.

**Secuencia:** contratar → derivar → implementar → revisar → producir evidencias → aceptar. Un equipo pequeño puede ejecutar estas etapas con un único agente en dos sesiones separadas, siempre que la revisión sea independiente del argumento del implementador.

## Comprobación de competencia

1. Formula la propiedad central como un predicado explícito, indicando el dominio y las condiciones de definibilidad.
2. Justifica una transformación algebraica relevante sin usar solo ejemplos concretos como prueba.
3. Construye un caso límite que pueda refutar una hipótesis insuficiente.
4. Declara qué parte está demostrada y cuál constituye solamente evidencia experimental.
