# 6.3 — Búsqueda binaria

## Competencias de esta sección

- **Conocimiento:** definir con precisión los términos y expresiones de «búsqueda binaria».
- **Desempeño:** aplicar el cálculo de predicados y las transformaciones justificadas en un problema concreto.
- **Evidencia:** entregar una especificación o derivación anotada, con hipótesis explícitas y límites de validez.

> **Referencia:** Kaldewaij, cap. 6, sección 6.3, página impresa 98. [Ver página original](../recursos/libro-original-escaneado.pdf#page=112).

## Desarrollo

Para una función `f` no decreciente y un valor objetivo `a`, buscamos el primer índice `r` donde `f.r≥a`, o `N` si ninguno existe.

Postcondición:

$$\begin{aligned}
0\le r\le N\ \land
&(\forall i:0\le i<r:f.i<a)\\
\land\ &(\forall i:r\le i<N:f.i\ge a).
\end{aligned}$$

**Invariante de fronteras:**

$$I\equiv0\le l\le h\le N\land
(\forall i:0\le i<l:f.i<a)\land
(\forall i:h\le i<N:f.i\ge a).$$

El segmento `[l,h)` todavía no está clasificado. Inicialización `l,h:=0,N` establece rangos descartados vacíos. Para `l<h`, elegimos `m=(l+h) div 2`:

- Si `f.m<a`, por orden `f.i<a` para todo `i≤m`; hacemos `l:=m+1`.
- Si `f.m≥a`, por orden `f.i≥a` para todo `i≥m`; hacemos `h:=m`.

```text
l,h := 0,N;
do l<h →
   m := l+(h-l) div 2;
   if f.m<a → l:=m+1
   [] f.m≥a → h:=m
   fi
od;
r:=l
```

**Por qué la mitad:** cada paso reduce aproximadamente a la mitad la longitud `h-l`, medida entera no negativa. **Costo:** `O(log(N+1))`; memoria `O(1)`. El índice de inserción está definido también para `N=0`.

## Comprobación de competencia

1. Formula la propiedad central como un predicado explícito, indicando el dominio y las condiciones de definibilidad.
2. Justifica una transformación algebraica relevante sin usar solo ejemplos concretos como prueba.
3. Construye un caso límite que pueda refutar una hipótesis insuficiente.
4. Declara qué parte está demostrada y cuál constituye solamente evidencia experimental.
