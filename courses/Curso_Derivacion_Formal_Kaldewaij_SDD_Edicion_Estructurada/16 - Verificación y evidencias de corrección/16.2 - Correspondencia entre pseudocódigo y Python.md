# 16.2 — Correspondencia entre pseudocódigo y Python

## Competencias de esta sección

- **Conocimiento:** definir con precisión los términos y expresiones de «correspondencia entre pseudocódigo y python».
- **Desempeño:** aplicar el cálculo de predicados y las transformaciones justificadas en un problema concreto.
- **Evidencia:** entregar una especificación o derivación anotada, con hipótesis explícitas y límites de validez.

> **Material complementario original:** aplicación actual de los métodos de Kaldewaij; no corresponde a una sección del libro de 1990.

## Desarrollo

| Elemento de derivación | Riesgo en código | Verificación recomendada |
|---|---|---|
| Asignación simultánea | Reutilizar valor ya actualizado | Comparar con temporales/tuple assignment |
| Guardas múltiples | Convertir no determinismo en prioridad incorrecta | Analizar superposición y postcondiciones de todas las ramas |
| División entera | Truncamiento distinto en negativos | Declarar dominio y semántica `div/mod` |
| Índice `f.n` | Acceso fuera de rango | Probar `0≤n<N` antes de indexar |
| Reales | `NaN`, infinitos, error de redondeo | Restringir dominios y tolerancias justificadas |
| Recursión/ciclo | Falta de terminación | Función acotada o contrato externo |
| Tiempo `O(N)` | Costos ocultos (I/O, estructuras) | Definir modelo de costo y medir |

## Comprobación de competencia

1. Formula la propiedad central como un predicado explícito, indicando el dominio y las condiciones de definibilidad.
2. Justifica una transformación algebraica relevante sin usar solo ejemplos concretos como prueba.
3. Construye un caso límite que pueda refutar una hipótesis insuficiente.
4. Declara qué parte está demostrada y cuál constituye solamente evidencia experimental.
