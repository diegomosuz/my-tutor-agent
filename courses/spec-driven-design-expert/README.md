# Spec-Driven Design (SDD) — Curso Experto

Curso completo en español preparado para **PwC AI Tutor**, siguiendo el formato oficial del proyecto.

## Propósito

Desarrollar dominio práctico y profundo de Spec-Driven Design / Spec-Driven Development:
ingeniería de requisitos, especificaciones verificables, diseño trazable, ejecución agentic,
calidad, gobernanza, brownfield y operación empresarial.

El curso es **tool-aware pero no tool-dependent**. Usa GitHub Spec Kit, Kiro y Claude Code
como implementaciones y herramientas de referencia, pero enseña principios transferibles.

## Nivel

Intermedio → avanzado → experto.

## Estructura

1. Fundamentos de SDD
2. Ingeniería de requisitos
3. Artefactos y trazabilidad
4. GitHub Spec Kit en profundidad
5. Kiro, Claude Code y ecosistema
6. Diseño técnico especificado
7. Ejecución agentic controlada
8. Calidad, gobierno y seguridad
9. Brownfield y escala empresarial
10. Capstone experto

## Convenciones técnicas

- Cada directorio `NN-*` es un módulo.
- Cada archivo `NN-*.md` es un tópico.
- Todos los tópicos usan YAML frontmatter.
- Los assets raster viven en `images/` dentro de cada módulo.
- Se usan tablas, fenced code, blockquotes, listas, task lists y diagramas PNG.
- No se usa HTML crudo.
