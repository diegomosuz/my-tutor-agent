# Formato de texto en Markdown

Este tópico no introduce conceptos nuevos de IA: es un **fixture visual**
para verificar que el aula virtual renderiza correctamente los elementos
básicos de Markdown que ya usan el resto de los tópicos del curso.

## Énfasis

Un texto puede tener **negrita**, *cursiva*, o combinar ambas como
***negrita y cursiva a la vez***.

## Listas

### Lista no ordenada

- Percepción: capturar información del entorno.
- Razonamiento: procesar esa información para tomar decisiones.
- Actuación: ejecutar una acción sobre el entorno.

### Lista ordenada

1. Definir el problema que el sistema de IA debe resolver.
2. Recolectar y preparar los datos disponibles.
3. Entrenar o configurar el modelo.
4. Evaluar los resultados antes de desplegar.

### Lista anidada

- Componentes de un agente
  - Percepción
    - Sensores de entrada (texto, imagen, audio)
  - Razonamiento
    - Planificación
    - Selección de herramientas
  - Actuación

## Cita

> La calidad de un sistema de IA depende tanto de los datos con los que
> se entrena como de las decisiones de diseño sobre cómo se usa.
