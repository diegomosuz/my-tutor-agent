# Componentes de un sistema de IA

Todo sistema de IA está compuesto, en general, por los siguientes bloques:

## 1. Datos

Los datos son la materia prima del sistema. Su calidad, volumen y
representatividad determinan directamente la calidad de los resultados que
el sistema puede producir.

## 2. Modelo

El modelo es el componente que aprende patrones a partir de los datos de
entrenamiento y los utiliza para generar predicciones o decisiones sobre
datos nuevos.

## 3. Proceso de entrenamiento

Es el procedimiento mediante el cual el modelo ajusta sus parámetros
internos utilizando los datos disponibles, con el objetivo de minimizar el
error en sus predicciones.

## 4. Infraestructura de servicio (inferencia)

Una vez entrenado, el modelo necesita ser desplegado en una infraestructura
que permita recibir solicitudes y devolver resultados en producción.

## Resumen

- Datos, modelo, entrenamiento e infraestructura de servicio son los
  cuatro componentes centrales de un sistema de IA.
- La calidad de los datos es un factor determinante del resultado final.
